같은 1인가구, 같은 어려움일까? — 배포 안내

1. 이 폴더 안의 파일을 GitHub 저장소 최상위에 올리세요. ZIP 자체는 올리지 않습니다.
2. 기존 app.py와 requirements.txt를 새 파일로 교체하세요.
3. app.py만 교체하면 안 됩니다. core.py, analytics.py와 모든 CSV/JSON/PDF를 함께 올리세요.
4. 이 패키지의 파일은 모두 한 폴더에 두면 됩니다. 데이터 파일은 data/ 안에 두어도 됩니다.
   같은 이름의 파일이 루트와 data/에 서로 다른 내용으로 있으면 앱은 중단합니다.
5. Streamlit Cloud 설정: Branch=main, Main file path=app.py, Python=3.12 권장.
6. 변경 반영 후 필요하면 Reboot app을 누르세요. 방문자는 업로드할 필요가 없습니다.

실행에 필수인 파일 13개
app.py / core.py / analytics.py / requirements.txt
source.csv / source.pdf / provinces_2020.json / seoul_2020.json
depression.csv / survey_cube.csv / survey_definitions.json / survey_audit.json / data_manifest.json

그 외 파일은 개발·재현·검증용이며 배포 시 있어도 됩니다.
개별 복지조사 Excel/SAV는 공개 GitHub에 올리지 마세요. 배포에는 집계 CSV만 필요합니다.

로컬 실행
python -m pip install -r requirements.txt
python -m streamlit run app.py

테스트
python -m pip install -r requirements-dev.txt
python -m pytest -q test_app.py

개인 PC에서 원자료로 집계 재현(원본은 별도 private_sources 폴더에 보관)
python build_data.py --raw-dir private_sources --output-dir .
python refresh_manifest.py --assets-dir .

원자료 사용 원칙
- 기존 CSV/PDF와 새 우울감 CSV는 원본 바이트 그대로입니다.
- 복지조사는 원본 Excel을 읽어 공식 코드북과 대조한 파생 집계를 생성했습니다.
- 원본의 공란/응답/가중치/ID는 고치지 않았습니다. 소득·지출 기준은 2023년입니다.
- 가구 Excel은 3,004가구이며 1인가구 표본은 821가구입니다.
- 가구원 Excel은 6,251행입니다. IDX 집합이 가구 파일과 달라 연결하지 않았습니다.
- 두 SAV는 체크섬과 헤더 표본수만 확인한 보조 원본입니다. 계산에 합산하지 않습니다.
- 현재 무부채 1,914가구의 부채 문항 공란은 비해당이며 0점으로 대체하지 않았습니다.
- 분자/분모 가중합으로 비율을 산출합니다. 연령별 비율을 단순 평균하지 않습니다.
- 설계기반 표준오차/신뢰구간을 만들지 않았으므로 유의성/인과효과를 주장하지 않습니다.
- 복지조사 지역은 5개 권역뿐입니다. 자치구별 경제적 취약가구 수는 추정하지 않습니다.
- 우울감 CSV는 전체 주민 지표입니다. 1인가구 우울률로 표시하거나 가구 수에 곱하지 않습니다.
- 지도는 SGIS 기반 2020 참고 경계이며 2025년 법정 경계나 실제 가구 위치가 아닙니다.
- 발표자료의 회귀계수/군집을 복사하지 않았습니다. 군집은 현재 CSV로 재계산합니다.
